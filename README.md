# Тулома · журнал о геометрии пространства

Главная, статья о геометрической видимости и лаборатория LOS. Общий виджет
использует одну реализацию NumPy для встроенного опыта и отдельной лаборатории.

Для сборки нужны Quarto, Python и NumPy. Запустите `./build.sh` и откройте
`dist/index.html` через статический HTTP-сервер. Сборка формирует контрольные
сценарии и иллюстрацию с теми же функциями, которые запускаются в браузере.
Для произвольных параметров браузер загружает Pyodide и NumPy.

## Запуск без сборки

В `dist/` уже находится готовый сайт. Его можно разместить на любом статическом
HTTP-хостинге или открыть локально через сервер Python:

```bash
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000/`. Запуск через `file://` не подходит для загрузки
исходника Python, JSON и Web Worker. Сервер только отдаёт файлы; вычисления
выполняются в браузере посетителя.

## Сборка из исходников

Проверено с Quarto 1.10.19, Python 3.12.14 и NumPy 2.3.5. Установите Quarto,
Python 3.11 или новее и создайте окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
./build.sh
python -m http.server 8000 --directory dist
```

Quarto включает Pandoc и Lua, используемые для формул, библиографии и псевдокода.
Скрипт также поддерживает отдельно установленный Pandoc, если Quarto отсутствует.
Для публикации достаточно содержимого `dist/`; Python и Quarto на хостинге не нужны.

## Зависимости при чтении

Сайт не использует API, авторизацию, серверные вычисления или ключи OpenAI.
Файл `.openai/hosting.json` нужен только для существующей публикации в Sites;
для самостоятельного размещения он не требуется. Адрес в поле `id` CSL-стиля
служит идентификатором стиля и не загружается браузером.

- Pyodide 0.29.4 и входящий в его дистрибутив NumPy загружаются при запуске
  Python с jsDelivr, с резервной загрузкой с unpkg. Версия браузерного NumPy
  определяется зафиксированным дистрибутивом Pyodide; `requirements.txt`
  фиксирует NumPy для локальной сборки.
- Lit 3.3.1 загружается с jsDelivr как необязательный слой визуализации.
  При его недоступности используются штатные SVG и элементы управления.
- Шрифты, формулы MathML, PDF, исходник LOS и контрольные сценарии размещены
  в самом проекте. Для чтения статьи и готовых сценариев сервер Python-расчётов не нужен.

Текущая сборка независима от бэкенда OpenAI, но для первого запуска Python
нужен доступ к CDN. Полный офлайн-режим потребует локального размещения
дистрибутива Pyodide, пакета NumPy и Lit с заменой адресов в `assets/worker.js`
и `assets/main.js`.

## Ссылки и алгоритмы в статьях

Библиография хранится в `assets/references/references.bib`. Для ссылки в тексте
используйте `[@katz2024]` или `[@katz2024, раздел 1]`. Quarto/citeproc формирует
номера, переходы и список в блоке `#refs` автоматически. Стиль задаёт локальный
`assets/references/tuloma-numeric.csl`. Кнопка BibTeX позволяет читателю забрать
библиографические записи. PDF размещаются в `assets/papers/` при наличии
разрешения на распространение, ссылка добавляется в `note` соответствующей
записи. Происхождение и лицензии файлов указаны в `assets/papers/README.md`.

Псевдокод набирается в блоке `.pseudocode`. Отступ в два пробела задаёт уровень
вложенности; нумерация алгоритмов и строк, направляющие и выделение ключевых
слов формируются при сборке. Формулы между `$` обрабатывает Pandoc, как в тексте
статьи. Поддерживаются русские и английские ключевые слова; Markdown, ссылки и
комментарии `//` допустимы внутри строк. Размер отступа можно задать `indent="4"`.

````markdown
```{.pseudocode #alg-example caption="Название алгоритма"}
Вход: $X$, порог $\varepsilon$
Для каждого $x \in X$:
  Если $x > \varepsilon$:
    Вернуть $x$
Вернуть $\varnothing$
```
````

На блок можно ссылаться как `[алгоритм](#alg-example)`, на строку —
`[строка 3](#alg-example-L3)`. Пример LOS размещён
в `includes/_article.md`, фильтр — в `filters/pseudocode.lua`, оформление —
в `.algorithm` в `assets/style.css`.

Основная статья подключается из `includes/_article.md` через `los.qmd`.
`build-lesson.py` создаёт статические SVG, состояния интерполяции и доказательства,
а также исходную узловую таблицу из общего модуля Python. Основной Worker
запрашивает `diagnostics=True`: строки `diagnostics.nodes`, ломаная
`diagnostics.difference` и `below_segments` получены на стороне Python.
`assets/lesson.js` рисует их и переключает выбранную строку. Учебный пример
и текущие параметры главного графика выбираются явно.

Для автоматической нумерации используйте блоки `.equation`, `.numbered-figure`
и `.numbered-table` с уникальным id; для рисунков и таблиц задайте `caption`.
Ссылка `[формуле](#eq-line){.xref}` получает номер автоматически. Идентификаторы
рисунков начинаются с `illustration-`, таблиц — с `table-`: эти имена оставляют
нумерацию нашему фильтру `filters/article-refs.lua`, без второго счётчика Quarto.

Проверка ядра: `python -B -m unittest discover -s tests`.

Ссылка на лабораторию кодирует координаты A и B, высоты точек, режим,
шаг равномерной выборки и изменённые отметки узлов. Стандартные сценарии
доступны сразу после загрузки страницы.
